EDIT WORKSPACE

Give the timeline the screen.

A larger timeline, resizable preview and one inspector for the selection. Arrange clips, look keyframes and FX layers with space to work.

EVERYDAY WORKFLOW

Keep the project moving.

Drag in a new audio track without replacing your visual source. Use native Save As to choose where your collected project belongs.

PERFORMANCE

Put your hands on the look.

Play Energy, Motion, Texture and Colour macros. Record their movement to the track, edit automation points or map MIDI CC knobs.

LIVING SOURCES

Let the material evolve.

Explore Living Emulsion, flowing Pigment and Impact Glass. Start with a generated surface, then bring footage into the mix.

DEPTH EXPERIMENTAL

Work with distance.

Import or locally generate relative depth maps to guide effects. Pair them with a subject matte to protect a performer. Video depth can flicker; generation needs the optional ROTO environment.

Installing on a Mac

Choose the download that matches your Mac’s chip in Apple menu → About This Mac. The current Mac build needs macOS 12 or later and Apple Silicon (M1 or newer). Intel Macs are not supported by this download.

  1. Download the ZIP and let it finish, then unzip it.
  2. Drag MATTE·LAB.app to Applications.
  3. Read the installation notes included with the release before the first launch.

This preview is not signed with an Apple Developer ID or notarized by Apple, so macOS may block the first launch. If the warning is about an unidentified developer or an app Apple cannot check, and you choose to trust this download, Apple provides System Settings → Privacy & Security → Open Anyway after an attempted launch.

If the message specifically says “damaged”, download the latest ZIP again and compare its checksum below. If it still fails, keep the exact warning and your macOS version when reporting it. A working download link cannot guarantee launch on every Mac.

Installing on Windows
  1. Download the Windows ZIP.
  2. Extract the entire folder.
  3. Open MatteLab.exe.

This build has no verified publisher signature, so Windows may show a SmartScreen prompt. Check the download source and the release notes before proceeding.

Optional tools: stems, ROTO and depth

The visual engine works without the ROTO toolkit. Stem separation downloads its model on first use. ROTO uses a separate local Python environment and model downloads; depth generation in the 2.35 series uses that environment too.

Download the toolkit for your platform and follow its release instructions. Imported depth maps do not need local generation.

Check a download’s integrity

A SHA-256 checksum confirms that your file matches the published asset. Compare it before opening if a download looks incomplete or macOS reports damage. A matching checksum does not mean Apple has notarized the app.

On macOS, use shasum -a 256 followed by the path to your downloaded ZIP. On Windows, use PowerShell’s Get-FileHash with the path to the ZIP and -Algorithm SHA256.
